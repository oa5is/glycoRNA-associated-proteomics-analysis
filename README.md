# glycoRNA-associated-proteomics-analysis
Custom R scripts and processed LFQ proteomics data for identification and downstream analysis of glycoRNA-associated proteins using rGAL- and rPAL-based enrichment.

# Quantitative GlycoRNA Associated Proteomics Analysis

This repository contains the processed label-free quantitative (LFQ) proteomics data using FragPipe(v23.1) and custom R scripts used for the downstream analysis of glycoRNA-core associated proteins enriched using **rGAL** and **rPAL** labeling strategies.

## Overview

The proteomics datasets were generated to characterize proteins associated with glycoRNAs following enrichment using two complementary bioorthogonal labeling approaches:

* **rGAL**: galactose oxidase-based oxidation targeting galactose (Gal) and N-acetylgalactosamine (GalNAc)-containing glycans.
* **rPAL**: periodate oxidation-based labeling targeting terminal sialic acid-containing glycans.

The processed protein-level LFQ intensity tables generated by FragPipe were used as input for downstream statistical analysis in R.

## Proteomics data processing

Raw mass spectrometry data were processed using **FragPipe (v23.1)**. Protein-level label-free quantification values were obtained from the resulting `combined_protein.tsv` files.

The FragPipe parameter and workflow files used for each dataset are included in the corresponding `LFQ_rGAL/` and `LFQ_rPAL/` directories to facilitate reproducibility.

## Downstream analysis

The custom R pipeline performs the following steps:

1. Import of FragPipe protein-level LFQ data.
2. Removal of keratin and keratin-associated protein **contaminants**.
3. Assignment of protein/gene identifiers.
4. Extraction and log2 transformation of MaxLFQ intensities.
5. Detection filtering, retaining proteins detected in **at least 2 of 3 replicates** in at least one experimental group.
6. Identification of condition-specific proteins (**>=2/3 replicates in one group and 0/3 in the other**).
7. Classification of missing values as **missing at random (MAR)** or **missing not at random (MNAR)**.
8. Mixed missing-value **imputation**:
   * K-nearest neighbors (KNN) for MAR values.
   * Quantile regression imputation of left-censored data (QRILC) for MNAR values.
9. Principal component analysis (PCA).
10. Differential protein abundance analysis using **limma**.
11. Volcano plot visualization.
12. Gene set enrichment analysis (GSEA) using GO Biological Process, GO Cellular Component, GO Molecular Function, and KEGG gene sets.

## Running the analysis

Clone or download this repository and set the repository root as the working directory in R.

The analysis script can then be run using:

```r
source("GlycoRBP_LFQ.R")
```

Input files should remain in their corresponding directories:

```text
LFQ_rGAL/combined_protein.tsv
LFQ_rPAL/combined_protein.tsv
```

Analysis outputs, including filtered protein tables, imputed LFQ matrices, differential abundance results, PCA plots, volcano plots, and GSEA results, are generated by the R script.

## Statistical analysis

Proteins detected in at least two of three replicates in either experimental condition were retained for downstream analysis.

Differential protein abundance was assessed using the **limma** framework with empirical Bayes moderation. Multiple-testing correction was performed using the Benjamini-Hochberg method.

For GSEA, proteins were ranked using moderated *t*-statistics from limma. Enrichment analysis was performed using `fgsea` with gene sets obtained through `msigdbr`.
